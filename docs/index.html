VAULT-0001 · SEAL CHECKER

Verify a sealed vault box from public BSV chain data. No trust in the seller, the issuer, or this page's operator — the proof is the chain itself.
What this proves: the box output carries the canonical VAULT-0001 covenant (the consensus-enforced state machine), its on-chain state byte is SEALED or OPENED, and that exact UTXO is unspent. State can only move SEALED→OPENED and the content commitment is immutable — both enforced by miners, not by any website.

v0.1 scope: checks the exact UTXO you point at. Full lineage tracing (genesis → current) is indexer work tracked in the spec. Mystery-box opacity (contents hidden until opening) is the VAULT-0002 committee extension — see the spec.
