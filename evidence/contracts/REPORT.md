## Reproduction
From this feature root, install locked vault dependencies with `npm ci --ignore-scripts --no-audit --no-fund` inside vault/. Then `python evidence/contracts/run-gates.py`. On Windows mint/test/run.js uses WSL login-shell Node and fixture key files on the Linux filesystem. No node or live adapter command is needed. Direct offline replay: `node evidence/contracts/replay-proof.js evidence/contracts/proof.json evidence/contracts/fixture-trusted-policy.json`; that policy is an explicitly PUBLIC TEST issuer, not production trust. Recovery: `node mint/scripts/recovery-inspect.js ABS_SALES_JSONL ABS_POOL_JSONL ABS_OBSERVATIONS_JSON SALE_ID SPONSOR_PUBLIC_KEY DEPTH`. Exit 2 means inconsistent/unreadable evidence; exit 0 is classification only, never permission to resume.

No compiler rebuild was needed or performed because covenant source/bytecode did not change. Existing compiled Script was exercised; compiler reproducibility is not newly established.
