## Visual verdict and limits
Actual source, mobile, open and rear-open captures inspected. The complete artifact is framed without clipping and shows a steep rounded needle above a green canopy relief with brass fittings. This is a **stylized miniature**, not photorealistic, geographically exact or botanically specific. The source poster is visibly grainy (24 Cycles samples, no denoising); stone reads medium gray-green under studio lighting rather than very dark raw volcanic rock. The needle is blunt, with restrained fluting; forest canopy is rounded and abstract. No scans or sacred/traditional patterns are claimed.

The front full-open view naturally hides the landscape behind the lid; `desktop-open-rear.png` demonstrates it remains present. Small inherited hinge/hasp attachments can appear separated at normal screenshot scale; the ten saved-source hinge attachment tests pass, but no claim of visually perfect mechanical realism is made. Body, inner liner, brass and unseen back are authored collection interpretations.

The technical gates passed on first execution; no production failure-and-fix was observed. Deliberate detached-needle, invalid-geometry and corrupt-parser failures are preserved as negative evidence. Shared main-checkout build dependencies were absent (actual compiler entrypoint missing), so pinned packages were installed only in this new directory. No sibling dependency folder was modified.

## Reproduce
Requires Blender 5.2.1, Python with Pillow/numpy/Playwright, Node and installed Edge for tests. `npm ci --ignore-scripts --no-audit --no-fund` restores the included package lock in this directory. Build dependencies are not runtime dependencies.

1. `python maps.py`
2. `blender --background --factory-startup --python-exit-code 1 --python author.py`
3. Run Blender similarly on `verify_theme.py`, `verify_pivots.py`, `verify_parity.py`, `verify_source.py`.
4. `node tests.mjs`; `python build.py`
5. `python verify_browser.py`; `python verify_extended.py`
6. `python package_delivery.py`

Authoring overwrites generated source, GLB and poster. Keep manual edits in a separate copy. `setup.py` records the one-time bootstrap from sibling Japan pilot and is **not needed for standalone reproduction**; the complete generated author and baseline are included. All routine reproduction paths are folder-relative. Source maps are independently authored, not downloaded photos. Three.js 0.180.0 MIT license is included; esbuild 0.25.11 is build tooling. Source citations and measurable pre-model contract are in `design-brief.md`.

User waived per-asset human review for the full 201-design collection. This pilot is autonomously delivered with technical/visual evidence, not described as human-approved. Branch backup only; integration and collection gallery belong to the separate final card.
