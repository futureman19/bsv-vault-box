## Visual limits
Actual mobile screenshot inspected: woven straw body and dark bespoke chevrons read clearly; understated gold fittings and shallow wetland miniature. The thin blue-green channels are less legible than the basket pattern at the default low viewing angle; it can read as a miniature garden without the title. Stylized, not photorealistic, a geographical map, an authentic artisan-made basket or cultural endorsement. No named traditional motif copied; rear/interior and fittings are contemporary extrapolations. No per-asset human review was required for this batch.

## Reproduce
Python with Pillow/numpy/Playwright, installed Edge, Blender 5.2.1 and pinned Three 0.180.0 / esbuild 0.25.11 (MIT license included). `build.py` uses local node_modules or the sibling pilot's installed dependencies; install this folder's package.json for standalone rebuilding. Runtime needs no dependencies/network.

1. `python maps.py`
2. `blender --background --factory-startup --python-exit-code 1 --python author.py`
3. `python build.py`; `node --test tests.mjs`
4. Run Blender with `verify_source.py`, `verify_parity.py`, `verify_contract.py` using the same background flags.
5. `python verify_browser.py`; `python verify_theme.py`
6. `python package_delivery.py`

Regeneration overwrites authored outputs. Archive excludes node_modules, backups and optional lane logs. All required runtime/source/evidence files are included and read back. Inventory excludes itself, archive and delivery-check to avoid recursion. Folder-local Git attributes preserve exact bytes.

Local art only: no deployment, minting, keys, blockchain queries, shared kit edits or changes outside this new preview. Branch backup only; integration is a separate card. Collection direction is 201 equally one-of-one designs.
