## Visual limits
A stylized red lacquer-inspired chest with thick rounded floral relief and contemporary diamond ornament, not intricate historical carving, a botanical peony reconstruction or photoreal reference equivalence. Floral clusters read at native mobile size; leaves and stems are simpler/angular. Dark .108-high seam is deliberately conspicuous. Family hardware is cleaner and larger than a museum box's fittings. Rear/interior are collection extrapolations. Poster retains modest Cycles sampling grain. No human per-asset visual approval claimed; user waived individual review until collection assembly.

## Reproduce
Blender 5.2.1, Python with numpy/Pillow/playwright, installed Edge, Node with `npm ci --prefix preview/china-v1 --ignore-scripts --no-audit --no-fund`. Exact Three 0.180.0 / esbuild 0.25.11 pins inherited; runtime license included. Build uses preview-local dependencies, no sibling directory writes. Native Windows tool paths in verify_all.py should be adjusted on other hosts.

`python preview/china-v1/verify_all.py --author` regenerates maps/source/render and runs build, source, parity, theme, motion, browser and extended gates. Omit `--author` to check saved delivery. `python preview/china-v1/package_delivery.py` refreshes inventory/archive after checks. Regeneration overwrites output; preserve manual edits separately. No source authoring requires sibling art. Dependencies are build-only and excluded from ZIP.
