## Visual assessment and limits
Actual source/mobile captures show a seated pale caldera, clearly visible depressed blue lake, wide charcoal chest and brass family hardware. Stylized faceted walls, procedural mineral grain and some Cycles sampling noise remain; no photorealistic, geographic, artisanal or reference-equivalence claim. The lake is smaller and partly hidden at the normal mobile angle. Body appears blue-gray under studio lighting rather than neutral black. Rim extrema are 2.292–2.568, a disclosed modest departure from the brief's approximate 2.35–2.55 target; the shallow lake still sits below every rim vertex. Border geography is shared with China; this is landscape inspiration, not a territorial assertion. No flags, leaders or political iconography.

## Reproduce
Blender 5.2.1; Python with Pillow/numpy/playwright; installed Edge; Node build tooling (not a blockchain node). Only this new preview directory is changed. The prescribed shared dependency directory was empty, so the same pinned package dependencies were installed locally; no shared preview was altered.
1. `npm ci --prefix preview/north-korea-v1 --ignore-scripts --no-audit --no-fund`
2. `python preview/north-korea-v1/maps.py`
3. Blender `--background --factory-startup --python-exit-code 1 --python preview/north-korea-v1/author.py`
4. `python preview/north-korea-v1/build.py`
5. Blender flags above with `verify_source.py`, `verify_parity.py`, `verify_theme.py` in this directory.
6. `node --test --test-reporter=tap preview/north-korea-v1/tests.mjs`; Python `verify_browser.py`, `verify_extended.py`, `package_delivery.py` in this directory.
`setup.py` records adaptation provenance and depends on sibling pilot files; do NOT rerun it on finished assets. Normal reproduction uses the included final scripts and mechanism only. Authoring overwrites generated source/export/poster. Dependencies are excluded from ZIP/Git. Three.js MIT license included.

Research URLs and pre-model visual contract are in `design-brief.md`. Nothing minted, broadcast, hosted, merged or deployed; no chain, keys, VPS or shared kit touched. Branch backup only; integration is a separate task.
