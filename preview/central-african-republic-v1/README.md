## Theme and visual verdict
The pre-model `design-brief.md` cites UNESCO's Sangha Trinational entry and its Central African Republic component, Dzanga-Ndoki. No third-party photographs or textures are embedded. This is an original landscape abstraction, not a particular tree species, traditional craft replica, geographical survey or representation of every culture in the country.

Warm dark timber, aged brass, green reveal and a low sandy clearing with small water inset, surrounded by seven broadleaf trees (35 canopy lobes). Actual source and mobile/rear-open captures were visually inspected. The wide box and broadleaf clearing read clearly; all major parts fit and no major component visibly floats. Deliberate limitations: the grove is sparse and stylized rather than dense rainforest, the sand reads as a thin raised miniature plaque, the water is tiny at mobile size, grain is regular/procedural, and lighting makes foliage lighter than its source material. The green reveal is conspicuous. No photorealistic, botanical or original-photo-equivalence claim. Hidden hinge contact is established by geometric tests, not fully visible in the rear screenshot.

## Failures and limits retained
The optional Codex lane failed HTTP 401/token refresh before making any edit; Hermes authored and verified directly without touching credentials. An initial `node` shell shim returned `stdin is not a tty`; tests use the native Node executable. The first browser run reached its no-errors/no-requests assertion and failed; the old harness did not serialize the messages, so the specific cause is unknown. `browser-log.txt` retains that failure. Diagnostic persistence was added, and subsequent complete runs passed without viewer changes; this is an unresolved transient observation, not a claimed fixed asset defect. One extended-check foreground attempt exceeded 90 seconds; the bounded tracked rerun and final suite completed. No gate was relaxed in response to these observations. The deliberate detached-canopy and corrupt-model controls demonstrate failing checks, not test-first development claims.

## Reproduction
Blender 5.2.1, Python with Pillow/numpy/Playwright, installed Edge, Node.js, Three.js 0.180.0 and esbuild. Node.js here is build tooling, never a blockchain node. Run from this directory:

1. `python maps.py`
2. `blender --background --factory-startup --python-exit-code 1 --python author.py`
3. `python verify_all.py` (build + all checks). Set `BLENDER_EXE` if not at the documented Windows default. Native Node path is selected on Windows.
4. `python package_delivery.py`

`build.py` uses local node_modules or sibling `iceland-pilot/node_modules`; in a standalone extraction run `npm ci` here first. Recovery verification found the shared compiler absent (`recovery-build-failure.txt`); the unchanged pinned dependencies were installed only in this preview, then all eight gates passed again. The local lockfile is included; node_modules is excluded. In the worktree the authorized dependency symlink was temporary and removed before commit. Runtime has no dependency on those folders. Regeneration overwrites authored assets; preserve manual edits separately. The source ZIP excludes itself, inventory envelopes, backups, caches and dependencies; inventory deliberately excludes itself and delivery/ZIP envelopes to avoid recursive hashes. Final report envelopes remain alongside the ZIP.

Mechanical/viewer/test lineage is Japan cedar v1 from base commit ff5d78f1e0d486af5c882c184fc08049996ebdc8, itself derived from the Iceland family. Visible Japanese tree/terrain are not reused. Shared `art/vault-kit/` is unchanged. Three.js MIT license is included. The compiled Three shader strings contain upstream trailing whitespace; whole generated-file `git diff --check` flags those strings. They are preserved rather than editing generated runtime bytes merely to satisfy formatting. Authored source-only whitespace checks pass. A directory-local `.gitattributes` disables text conversion so hashes survive Windows checkout.

Local art only: no keys, chain queries, blockchain nodes, minting, broadcasting, hosting, VPS changes or production edits. Only the country directory is committed; branch backup only, no merge. The collection remains 201 equally one-of-one designs; per-asset human review was waived for this batch. Storage/upload/issuance are not implemented by this art deliverable.
