## Reproduce
Python with numpy/Pillow/Playwright, installed Edge, Blender 5.2.1; Node build-time tool only. `npm ci --ignore-scripts` here; `python maps.py`; Blender `--background --factory-startup --python-exit-code 1 --python author.py`; `python build.py`. Run Blender similarly on `verify_source.py`, `verify_parity.py`, `verify_theme.py`; then `python verify_browser.py`, `python verify_extended.py`, `python package_delivery.py`. Source author and mechanism are self-contained; optional setup.py documents initial adaptation and requires sibling Japan pilot, but is not needed to reproduce the delivered source. Regeneration overwrites generated assets; preserve manual edits separately. No node_modules/cache/backups in archive.

Branch backup only; integration/gallery is the separate final collection task. Collection scope: 201 equally one-of-one designs; no launch accessories.
