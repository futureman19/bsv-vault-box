# Marshall Islands v1 — Pandanus & Swell

Open **marshall-islands-v1.html** directly in Edge/Chrome. All runtime code, GLB, maps and actual-model poster are embedded: **4,140,902 HTML bytes**, **2,491,908 GLB bytes**. Drag/touch rotates; Open/Close lid and Reset work offline, with reduced-motion support. Cosmetic animation only, not a custody action.

## Design and contents
A wide woven-pandanus-inspired chest, teal seam, satin brass hardware, low atoll/lagoon relief and a raised decorative wave-chart panel. Six bowed rods, two diagonals and four ivory markers sit on the lid. Research-backed `design-brief.md` was written before modeling. WAM and Smithsonian sources inform materials and wave-learning associations; the layout is invented, not an accurate traditional chart or geographic atoll. No artifact photographs or external textures are embedded.

Editable packed `marshall-islands.blend`, portable `marshall-islands.glb`, included `mechanism.blend`, four procedural maps, reproducible scripts, real source `poster.png`/`poster.jpg`, desktop/mobile closed/open/rear/fallback captures, JSON evidence, raw outputs and readback-verified source ZIP accompany the HTML. Three.js 0.180.0 MIT license included. The mechanism/viewer/check lineage is Japan Cedar v1 on repository base ff5d78f; original artwork is not reused. Shared vault kit and previous previews are unmodified.

## Verified acceptance
- **Source:** independent saved-file reopen; hollow interior ray hits floor at z=0.2650000155; ten hinge attachment pairs overlap as intended. All **43 moving and 99 static meshes**, including every ornament, tested through **81 poses**. No unexpected surface intersections. Only explicit original mating hinge/latch bearings excluded. This is sampled surface evidence, not continuous collision/manufacturing certification.
- **Parity:** source and imported GLB nearest-vertex bidirectional maximum error **1.712013073529306e-7**, below 1e-5. Four packed source images. Geometry equivalence is tested, not byte-identical re-export or every material factor.
- **Theme:** 15 lid-borne ornament meshes, six swell rods, four markers, declared height/footprint bounds, lagoon vertices inside the inner sand ellipse, and original pivot matrices exactly preserved. Deliberately detaching an ornament fails ancestry (`detached ornament`); restoring it passes. This is a post-authoring negative control, not a claim of test-first development.
- **Actual GLTFLoader:** **30,260 triangles, 142 meshes, 10 materials**, zero degenerate triangles/nonfinite vertices. Four decoded map channels vary; roughness is read from glTF GREEN. Maps are 512px or 256px.
- **Motion:** two Node tests exercise staged 80-degree latch / 105-degree lid endpoints, clamping and invalid-asset rejection.
- **Browser:** offline `file://` Edge, desktop 1440×1080 and touch-emulated mobile 390×844. Native buttons/taps, drag/touch rotation, open/close, interrupted reset, reduced motion, corrupt-GLB parser fallback, no-JS poster, no horizontal overflow and no external HTTP requests/runtime errors. Full-open max projected absolute NDC about 0.892365 (<1). Mobile is desktop-GPU emulation (RTX 4060), not a physical phone test.
- **Delivery:** strict <5,000,000-byte HTML assertion; explicit required-artifact inventory, exact SHA-256/byte counts and ZIP readback. `inventory.json` excludes itself, ZIP, delivery envelope and actively written packaging/Git logs to avoid recursive hashes. Folder-local Git attributes preserve exact bytes.

## Real failures and fixes
The prescribed sibling node_modules link led to an empty dependency directory; initial build failed `MODULE_NOT_FOUND`. The exact failure is retained in `initial/build-missing-dependencies.txt`. Installing the pinned dependencies locally in this new folder fixed the build without editing any prior preview. A shell `node` shim failed `stdin is not a tty`; `initial/node-shim-no-tty.txt` retains it. Calling the native Node executable passed both tests. No geometry, collision or browser threshold was relaxed; no art failure was hidden.

## Visual verdict and limitations
Actual source render and desktop/mobile browser images were inspected. Wide box, cream weave, lagoon-blue seam, atoll and raised chart are readable; model and UI are unclipped in tested views. Materials are stylized: regular texture grid rather than individually modeled interwoven fibers, pale rather than richly honey-colored under studio lighting, opaque enamel lagoon rather than refractive water, simplified brass and irregular stone-like feet. Fine chart geometry is small on mobile; lid relief naturally turns away in the front-open view (rear-open capture included). Poster has residual sampling noise. No photorealism, cultural endorsement, user art approval, accurate chart semantics or physical fabrication claim.

## Reproduction
From this directory: `npm ci --no-audit --no-fund`; `python maps.py`; Blender 5.2.1 `--background --factory-startup --python-exit-code 1 --python author.py`; `python build.py`. Run Blender with `verify_source.py`, `verify_parity.py`, `verify_theme.py`; run `node --test tests.mjs`, `python verify_browser.py`, `python verify_extended.py`, then `python package_delivery.py`. On this Windows host use `C:/Program Files/nodejs/node.exe` if the shell shim rejects non-TTY execution. Python requires numpy, Pillow and Playwright; browser checks require installed Edge. Dependencies/caches are not archived. Build uses local node_modules, otherwise the sibling Iceland installation; the source archive is self-contained after dependency installation. Regeneration overwrites outputs; retain manual edits separately and regenerate inventory after changes.

No production edits, hosting, blockchain/node queries, keys, transactions, minting, VPS access or deployment. Only the authorized art branch is backed up; final collection integration is separate. The 201-piece collection is equally one-of-one. Per-asset human review was explicitly waived until collection completion.
