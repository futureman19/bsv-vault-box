## Design and visual limits
The pre-model brief cites UNESCO's mountainous granite watershed, rainforest and lowland meanders. The miniature is invented, not a geographic reconstruction, botanical survey, traditional craft claim or replica of an approved illustration. Warm grey stone-like body, charcoal-green lid, brass hardware and two wooded banks around a continuous turquoise meander. Trees remain simplified rounded broadleaf clusters; the forest is relatively sparse and water is an opaque ribbon, not realistic flow. The river is visible on mobile but secondary to the chest. Source render has some sampling grain. No photoreal-equivalence claim.

Actual final mobile screenshot inspection found a clear wide chest silhouette, visible winding river and supported terrain. An initial source render (`initial-sheet-banks.png`) showed paper-like raised bank edges; authored perimeter sidewalls corrected this. Final browser and source gates were rerun. Closed/open desktop/mobile images show actual model, never promotional substitutes.

## Reproduce
Dependencies: Blender 5.2.1, Python with Pillow/numpy/playwright, installed Edge, Node.js build tooling (not a blockchain node). Run `npm ci --ignore-scripts --no-audit --no-fund` in this directory if dependencies missing. Build prefers local dependencies, otherwise sibling Iceland toolchain.

1. `python maps.py`
2. `blender --background --factory-startup --python-exit-code 1 --python author.py`
3. `python verify_all.py` (build; source, parity, theme; browser and extended checks)
4. `python package_delivery.py`

Authoring overwrites output; preserve manual edits separately. Inventory excludes itself, delivery report, source ZIP, dependencies, caches and .blend1 backups to avoid circular hashes. ZIP includes the inventory and all required source/model/viewer/evidence artifacts; delivery-check identifies its bytes/hash. Folder-local Git attributes preserve exact bytes. Regeneration changes identities; rerun packaging. This is an inner collectible cosmetic demonstration; no seal or on-chain state changes.
