# BoxSV repaired collection preview

Open `index.html` with this entire folder present, or serve the folder with any ordinary static HTTP server. All 201 interactive viewers live under `viewers/` and contain their own model, runtime, maps and fallback poster. No external runtime download is required.

`review.html` is a compact, standalone **poster-only** attachment: all 201 selected-model and promotional thumbnails, search, filters, comparison dialogs and immutable version details are embedded. It intentionally does not link to missing local viewers when sent alone.

`manifest.json` pins each selected viewer, embedded model, editable source, existing promotional artwork and derived actual-model poster. Source/editor archives are referenced by exact Git commit/path/SHA-256; they are not included in this hosting bundle. `inventory.json` identifies the delivered static files, not publisher authenticity. Trust this package or its archive hash through a separate channel.

This is not a final-art approval, NFT mint, sale, wallet interface or custody operation. Cosmetic opening affects only the displayed model. Ordinary stylization is disclosed per design; substantive feature gaps remain filterable. All 201 designs have equal planned one-of-one scarcity.

Publication is not performed by this delivery. Suggested isolated route: `/collection-preview/`. Copy the complete folder; do not upload just index.html. Production homepage/gallery/claw files remain untouched.
