What this proof does — and does not — say
This is a generated evidence snapshot of a completed local regtest run. The browser does NOT re-execute Script or node consensus. The exporter replays serialized transactions in the local Script VM and cross-checks saved RPC results before producing this file.
RPC confirmation and UTXO statements are historical records, not independently re-executed consensus or a live unspentness check. Ordinal mapping follows ordered sat ancestry; it is not native node awareness of NFT identity.
The certificate NFT carries only an on-chain hash of a detached signed statement. Issuer trust comes from an explicit external public-fixture policy, never from a claim inside the bundle. Certificate provenance is a client check, not covenant enforcement.
No claims of commercial miner acceptance, arbitrary NFT support, production readiness, file-storage durability, independent security audit, or resealing. This attachment is not hosted. The public BoxSV simulation is unchanged.
